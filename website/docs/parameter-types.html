Parameter types

A parameter type gives a name to a pattern and converts the matched text into a value. The step then receives a number, a date or an object, not a string.

Define one

This is the {money} type from examples/basic.

Options

defineParameterType({ name, regexp, transformer })

Registers a type that steps can use as {name}.

name
The word used in curly braces.
regexp
What the text must look like. Use a single regular expression, or an array of them.
transformer
Converts the matched text into the value the step receives. Receives one string per capture group.

Another example: a user role

Tip

A step that does not match gets reported as undefined with the text of the step, which tells you at once when a value is not in your type.

Validate

npx bddr validate checks steps without running parameter transformers, so it does not run your conversion code.
