Theme and components

Everything a docs page is built from, with the markup to copy. New pages start from docs/_template.html and use only what is on this page.

Colour

The palette comes from a test run: a deep cyan for the brand, run states for pass, fail, skip and flaky, and six group colours for schedules and plan diagrams. Code blocks stay dark in both themes. Switch the theme in the header to see the dark values.

Type

Three cuts of one family, IBM Plex, served from assets/fonts. Plex Sans Condensed for page and section titles, like the labels of a runner's output; Plex Sans for reading; Plex Mono for code. Body text is 17 px with lines kept under 72 characters.

Section heading, condensed 600

Sub-heading, Plex Sans 600

Body text in Plex Sans 400. A scenario that fails is retried once, and its screenshot is attached to the report. Strong text, emphasis, a link, inline code and Ctrl + C.

Code blocks

A figure.code-block with an optional data-title (usually the file path). The language class sets the colours and the label: lang-ts, lang-js, lang-gherkin, lang-bash, lang-powershell, lang-json, lang-html, or lang-text for none. Escape < as &lt; inside. Commands start with $ or PS> ; the copy button leaves the prompt out.

Tabs

For the same thing on different systems or with different plugins. Tabs with the same data-group switch together across the page and the choice is remembered; the os group opens on the reader's own system.

Callouts

Four kinds, each for one job. Use them sparingly: one or two on a page.

Note

Something worth knowing that is easy to miss.

Tip

A shortcut or a better way to do the same thing.

Warning

Something that surprises people, such as a retried scenario continuing on a shared page.

Danger

Something that loses data or breaks a run.

Steps

Only for things done in order. Each step can hold a heading, text and code.

  1. Install

    Run npm install.

  2. Build

    Run npm run build.

  3. Run

    Run npx bddr run.

Image placeholders

Where a page needs a picture that does not exist yet, it shows a placeholder that says how to get it. There are two kinds.

To generate with AI

Diagrams and illustrations. The caption holds a ready prompt with the theme's colours and font, and the file name to save it as.

To capture yourself

Real output: reports, terminals, the IDE. The caption says exactly what to run and what to capture.

Writing for these docs

  • Say what the reader does and what happens: "Run npx bddr plan to see the schedule", not "The plan command can be leveraged".
  • Sentence case for every heading. No all-caps labels.
  • Every code example must run as shown. Take them from examples/ or run them before publishing.
  • Show the Windows command in a tab whenever it differs from macOS and Linux.
