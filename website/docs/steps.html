bddr / Writing tests

Step definitions

A step definition connects a line of a scenario to code. Given, When and Then are interchangeable for matching, so use whichever reads best.

Your first step

The first argument is the context (see below). The values captured from the step text follow it. A step passes when it returns, or when its promise resolves. It fails when it throws.

Patterns

Patterns are Cucumber Expressions:

In the patternMatchesYou receive
{int}42a number
{float}3.5a number
{string}"apple" or 'apple'the text without quotes
{word}applea word
cat(s)cat or catsnothing
red/greeneither wordnothing

You can use a regular expression instead. Each capture group becomes an argument.

The context

The context is how steps share data and reach the framework.

PropertyWhat it is
ctx.stateData for this scenario. Gone when the scenario ends. get, set and getOrSet are typed.
ctx.feature, ctx.groups[name], ctx.runWider stores for a feature, a group and the whole run.
ctx.paramsValues from -D key=value and the config params.
ctx.scenarioId, name, tags, meta, the example row and the attempt number.
ctx.logLevelled logging: ctx.log.info('...'). ctx.log.image() attaches a screenshot.
ctx.attach(body, mediaType, name)Attach anything to the report.
ctx.softSoft assertions: check and run record a failure and let the step continue. The scenario fails at the end.
ctx.defer(fn)Run a cleanup when the scenario ends.
ctx.signalAn AbortSignal that fires on timeout or Ctrl+C. Pass it to APIs that accept one.
ctx.export, ctx.from(id)Pass values to dependent scenarios. See Dependencies.
ctx.page, ctx.request, ...Fixtures that plugins add. See Fixtures and inject().

Step options

  • timeoutMs: how long the step may take.
  • retry: run again until it passes. A number, or { attempts, delay, backoff }.
  • concurrent: false: this step never runs in parallel with itself. Use it for steps that drive a browser. @concurrency on such a step is an error.
  • tags: only match in scenarios whose tags satisfy the expression.

Repeat and retry from the feature file

Tags at the end of a step line repeat or retry just that step: @repeat:N, @retry:N, @delay:2s, @backoff:2, @timeout:10s and @concurrency:N. See Retries and flaky tests.
