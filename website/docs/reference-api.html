bddr / Reference

Runtime API

Everything you import from @bddr/runtime in step files. The config helper defineConfig comes from @bddr/cli.

Steps

Given(pattern, fn) · Given(pattern, options, fn)

When, Then and Step are the same function. The keyword does not affect matching.

pattern
A Cucumber Expression string or a regular expression.
fn
(ctx, ...captures) => unknown. The first parameter may be destructured to request fixtures. A trailing data table or doc string is the last argument.
options
{ tags, timeoutMs, retry, concurrent }. See Step definitions.

Used without a function, Given(pattern, options?) is a method decorator inside a @Steps() class.

defineParameterType({ name, regexp, transformer })

Adds a type for use as {name} in patterns. See Parameter types.

Hooks

Before(fn) · Before(tags | options, fn)

The same shape for every hook. A string is a tag expression. Options: name, tags, order, alwaysRun, timeoutMs, and eachAttempt for step hooks.

FunctionReceives
BeforeAll, AfterAll (BeforeSuite, AfterSuite)run context
BeforeWorker, AfterWorkerrun context
BeforeGroup, AfterGroupgroup context: adds group (store) and groupName
BeforeFeature, AfterFeature, BeforeRule, AfterRulefeature context: adds feature (store), featureInfo and rule
Before, After (BeforeScenario, AfterScenario), BeforeStep, AfterStepstep context

Fixtures and plugins

defineFixture(name, setup, options?)

Registers a named value created on first use. See Fixtures and inject().

setup
(ctx) => value | Promise<value>. Destructure other fixtures from ctx.
options.scope
'scenario' (default), 'feature' or 'worker'.
options.teardown
(value, { status, error, ctx }) => void | Promise.
options.afterScenario
Feature and worker scope only. Called after each scenario that used the fixture.
definePlugin({ name, setup(options) })

Returns the plugin object. Export it as the default export of a plugin file. See Writing your own plugin.

inject(token)

Used in a field or constructor of a class. token is a class (one instance per scenario), a fixture name, or CONTEXT. See Class steps and page objects.

@Steps() marks a class that holds step and hook methods. CONTEXT is the token for the step context.

Run-wide settings

setRetryAnalyzer(fn | undefined)

Decide for each failure whether to retry, like TestNG's retry analyzer. fn({ scenario, attempt, maxRetries, error }) returns true to retry or false to stop. It is called only when a retry is otherwise allowed.

setDefaultTimeout(ms)

The default timeout for steps and hooks, like stepTimeoutMs in the config.

Stores

ctx.state, ctx.feature, ctx.run and the group stores have get<T>(key), set(key, value) and getOrSet(key, factory).

Data

DataTable: raw(), header(), rows(), hashes(), rowsHash(), transpose(). DocString: a string with content and mediaType. See Data tables and doc strings.

Programmatic use

The CLI is a thin shell around runBddr() from @bddr/cli, so you can start a run from your own script. See packages/cli/src/run.ts in the repository.
