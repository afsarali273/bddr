Data tables and doc strings

A step can take one table or one block of text after it. The step receives it as its last argument.

Data tables

MethodReturns
raw()All rows as arrays of strings, including the header row.
header()The first row.
rows()All rows except the header.
hashes()One object per row, keyed by the header. The usual choice.
rowsHash()A two-column table as one object: first column keys, second column values.
transpose()A new table with rows and columns swapped.

Doc strings

A DocString is a string with a content and an optional mediaType.

Tables in reports

The HTML report shows step tables and doc strings as tables, tinted by the status of the step.

Tip

For many rows, or rows that change often, keep them in a file and use @data:. See Data files.
