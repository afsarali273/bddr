# @bddr/core

The spec model, Gherkin compiler, tags, selection, planner, run history and event schema. No browser or HTTP dependency.

Part of [bddr](https://github.com/afsarali273/bddr), a test runner for BDD scenarios with groups, dependencies, locks, retries and living documentation.
